## 1. Ringkasan Eksekutif
Tahap 2 berfokus pada penambahan 5 tool manipulasi halaman PDF. Seluruh tool pada tahap ini **hanya menerima 1 file input** (Single File Drop) dan menggunakan *shared components* serta *backend pipeline* yang sudah dibangun di Tahap 1.

**Prinsip Desain yang Mengikat:**
- **Whitespace & Simpel:** Layout harus lapang, tanpa teks bertele-tele.
- **Full-Rounded & Shadowless:** Wajib mengikuti `DESIGN.md` §2–§3.
- **Konsistensi:** Gunakan `ToolShell`, `FileDropZone`, `ProgressCard`, `ResultCard`, dan `ErrorAlert` yang sudah ada.

## 2. Spesifikasi Tool & UI

Untuk semua tool di tahap ini, perbarui `packages/shared/src/tools.ts` (`available: true`) dan buat halaman UI di `apps/web/src/app/tools/[slug]/page.tsx`.

### 2.1 Split PDF (`/tools/split-pdf`)
**Deskripsi UI:** "Split into separate files."
**Opsi UI (Gunakan komponen Tabs/RadioGroup):**
- **Mode 1: Ranges** (Input teks, cth: `1-3, 5, 8-10`). Output: Beberapa file PDF dalam bentuk ZIP.
- **Mode 2: Every N pages** (Input angka, cth: `2`). Output: ZIP.
- **Mode 3: Fixed ranges** (Pisah tiap 1 halaman). Output: ZIP.
**Backend Recipe (Python):**
- Gunakan `pikepdf`. Pisahkan halaman sesuai mode.
- Jika menghasilkan > 1 file, kompres ke `.zip` sebelum di-upload ke object storage.
**Validasi:** Input range tidak boleh kosong/tidak valid.

### 2.2 Remove Pages (`/tools/remove-pages`)
**Deskripsi UI:** "Delete specific pages."
**Opsi UI:**
- Input teks "Pages to remove" (cth: `1, 3, 5-7`).
**Backend Recipe (Python):**
- Gunakan `pikepdf`. Hapus halaman yang disebutkan.
- Validasi: Jika halaman yang dihapus >= total halaman, kembalikan error `INVALID_OPTIONS` ("Cannot remove all pages").
**Validasi UI:** Hanya menerima angka, koma, dan *dash* (strip).

### 2.3 Extract Pages (`/tools/extract-pages`)
**Deskripsi UI:** "Keep only specific pages."
**Opsi UI:**
- Input teks "Pages to extract" (cth: `1-3, 5`).
- Toggle Switch: "Extract each page as a separate file" (Jika aktif, output ZIP. Jika mati, output 1 PDF berisi halaman terpilih).
**Backend Recipe (Python):**
- Gunakan `pikepdf`. Ekstrak halaman.
- Jika toggle aktif, buat ZIP.

### 2.4 Rotate PDF (`/tools/rotate-pdf`)
**Deskripsi UI:** "Rotate pages."
**Opsi UI:**
- RadioGroup: "Rotate all pages" / "Select pages".
- Jika "Select pages", munculkan input teks (cth: `1, 3`).
- RadioGroup / Select: "90° Clockwise", "180°", "90° Counter-clockwise".
**Backend Recipe (Python):**
- Gunakan `pikepdf`. Iterasi halaman yang dipilih dan atur `page.rotate = (page.rotate + angle) % 360`.

### 2.5 Organize PDF (`/tools/organize-pdf`)
**Deskripsi UI:** "Reorder, rotate, or delete pages."
**Catatan UI (Sangat Kompleks):**
- Ini adalah tool *single-file* yang membutuhkan ekstraksi **seluruh halaman** menjadi *thumbnail*.
- Gunakan `pdfjs-dist` (seperti di Merge PDF) untuk merender semua halaman.
- Gunakan `@dnd-kit` untuk memungkinkan *drag-and-drop* antar halaman.
- Setiap halaman memiliki tombol "Rotate" (90°) dan "Delete" (X).
**Backend Recipe (Python):**
- Terima payload `options.pages: [{ originalIndex: 2, rotation: 90 }, { originalIndex: 0, rotation: 0 }]`.
- Gunakan `pikepdf`. Buat PDF baru, lalu salin halaman sesuai urutan `originalIndex` dan terapkan rotasi.

## 3. Backend Requirements (Updates)

1. **API Validation (`apps/api`):**
   - Buka kunci tool di registry (set `available: true` untuk 5 tool ini).
   - Pastikan `optionsSchema` di `packages/shared` menggunakan Zod untuk memvalidasi input di atas.
2. **Worker (`apps/worker`):**
   - Buat modul resep baru: `split_pdf.py`, `remove_pages.py`, `extract_pages.py`, `rotate_pdf.py`, `organize_pdf.py`.
   - Pastikan *output* ZIP didukung oleh `GET /api/v1/jobs/:id/result` (set header `Content-Type: application/zip` jika output ZIP).
3. **Frontend State:**
   - Untuk `organize-pdf`, karena memproses banyak halaman, gunakan *state management* lokal yang efisien (misal `useReducer` atau `Zustand` jika perlu) untuk menyimpan urutan halaman dan rotasi.
