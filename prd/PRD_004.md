## 1. Ringkasan Eksekutif
Tahap 4 berfokus pada konversi file eksternal ke dalam format PDF. Semua tool di tahap ini memerlukan *engine* tambahan di sisi worker (LibreOffice, img2pdf, dan Playwright).

**Prinsip Desain:** Wajib mengikuti `DESIGN.md`. Karena tool ini menerima format file selain PDF, pastikan UI `FileDropZone` menampilkan teks batasan file yang sesuai (misal: "Drop DOCX here", bukan "Drop PDF here").

---

## 2. Spesifikasi Tool & UI

Perbarui `packages/shared/src/tools.ts` (set `available: true`) dan buat halaman UI baru.

### 4.1 Word to PDF (`/tools/word-to-pdf`)
- **Accept:** `.docx`, `.doc`
- **Deskripsi UI:** "Convert Word to PDF."
- **Backend:** LibreOffice Headless (`soffice --headless --convert-to pdf`).
- **PENTING:** Jika file `.doc` (format lama) rusak atau tidak bisa dibaca, return error "Failed to convert document".

### 4.2 Excel to PDF (`/tools/excel-to-pdf`)
- **Accept:** `.xlsx`, `.xls`
- **Deskripsi UI:** "Convert Excel to PDF."
- **Opsi UI:** Toggle "Fit to page" (Default: true).
- **Backend:** LibreOffice Headless.

### 4.3 PowerPoint to PDF (`/tools/powerpoint-to-pdf`)
- **Accept:** `.pptx`, `.ppt`
- **Deskripsi UI:** "Convert PowerPoint to PDF."
- **Backend:** LibreOffice Headless.

### 4.4 JPG to PDF (`/tools/jpg-to-pdf`)
- **Accept:** `.jpg`, `.jpeg`, `.png`, `.webp`
- **Deskripsi UI:** "Convert images to PDF."
- **Opsi UI:**
  - Orientation: Portrait / Landscape.
  - Page Size: A4 / Letter / Fit to image.
  - Margin: None / Small / Big.
- **Backend:** Gunakan Python library `img2pdf`. (Sangat cepat dan *lossless* untuk gambar).

### 4.5 HTML to PDF (`/tools/html-to-pdf`)
- **Accept:** `.html`, `.htm` (file upload, bukan URL).
- **Deskripsi UI:** "Convert HTML to PDF."
- **Opsi UI:** Page Size (A4 / Letter).
- **Backend:** Gunakan **Playwright (Chromium)** di Python. Render file HTML lokal lalu ekspor ke PDF. (Pastikan Chromium sudah terinstal di Docker Worker).

---

## 3. Backend Requirements (Updates)

1. **Docker Worker (`apps/worker`):**
   - Instal `libreoffice` (headless mode).
   - Instal `playwright` dan jalankan `playwright install chromium` untuk dependensi HTML.
   - Instal `img2pdf` via pip.
2. **API Gateway (`apps/api`):**
   - Pastikan validasi file di `POST /jobs` memeriksa ekstensi/MIME type yang sesuai untuk masing-masing tool (jangan hanya mengecek `application/pdf`).
   - Tool Registry diperbarui.
3. **Worker Recipes:**
   - `word_to_pdf.py`, `excel_to_pdf.py`, `ppt_to_pdf.py`: Gunakan `subprocess.run(["soffice", "--headless", "--convert-to", "pdf", ...])`.
   - `jpg_to_pdf.py`: Gunakan `img2pdf`.
   - `html_to_pdf.py`: Gunakan Playwright.
